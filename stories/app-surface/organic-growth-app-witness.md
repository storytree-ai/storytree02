# The real app consumer stages the corrected organic-growth witness

> **RETIRED 2026-09-24 under ADR-0608.** The flat forest picture this capability painted is retired;
> the mounted 3D land is the forest. Its code and tests were deleted, and everything below is history.

**Outcome —** An exact query-gated mode of Studio's real shared-app consumer presents app-native SVG
land growth beneath registered local organic tracks through the public product player while ordinary
routes remain unchanged.

## Proof walkthrough first

Extend the real `TreeView` consumer integration proof:

1. render the clean route plus unknown and near-miss queries, proving each mounts the ordinary shared
   forest without organic-growth witness controls, assets or changed controller state;
2. render exact `?organicGrowth=demo#/tree` and prove real `TreeView` mounts one public
   `SemanticGrowthWorldView` composition through the shared `SceneView`, not a host-local renderer,
   movie/GIF, duplicate semantic cursor or replacement camera;
3. advance from `empty` through retained `healthy`, proving the existing SVG island/coast grows at
   the established camera before registered transparent hero-tree/canopy/plant tracks grow from
   their declared app-owned sockets;
4. walk Next, Back and Replay twice, then repeat under reduced motion; compare semantic cue,
   progress, native-land state, organic frame selection, sockets, painter order and retained output;
5. source-audit Studio, package dependencies and representative browser requests: no PixelLab client,
   hostname, credential, runtime model call, asset clock or generated island/composite enters the
   consumer;
6. exercise representative desktop and mobile host sizes, proving the native coast, planted roots,
   mature footprint and controls remain inside the real world framing without a viewport-specific
   renderer; and
7. preserve the existing clean Studio scene, selection, camera, inspector, chat, Storybook/Vector
   fallback and earlier semantic-demo suite outside the exact witness gate.

The post-merge hosted URL, network/performance inspection and viewport evidence are machine-observable
story evidence. Whether the corrected composition looks coherent and alive remains the owner's LOOK
judgment.

## Guidance

- Reuse real `TreeView` plus the public app-surface player, native-land mapper and organic-track
  registry. Host code supplies only representative read-only semantic inputs and an exact query gate.
- Keep clean, unknown and near-miss query behaviour ordinary. Do not add a permanent navigation entry
  for this bounded witness.
- Visible Next, Back and Replay controls drive the public player. Do not hide a host cursor, timer or
  remount key behind them.
- Load only local packaged organic assets over the real SVG island. Fail source/request audits on any
  runtime PixelLab dependency or generated island/coast composite.
- Verify the deployed real-app URL at representative desktop and mobile viewports before owner
  handoff. Screenshots and inspection exports supplement the live link; they do not replace it.
- Do not self-sign LOOK. The owner decides whether native land and organic raster tracks form one
  convincing product scene.

## Machine contracts

1. **`ogaw-exact-flag-mounts-one-real-shared-composition`**
   - **asserts —** only exact `?organicGrowth=demo` mounts one public shared player inside real
     `TreeView`; native-land progress, organic frame selection and `SceneView` come from
     `@storytree/app-surface`, with no host-local renderer, cursor, movie or alternate camera.
2. **`ogaw-clean-and-near-miss-routes-preserve-the-product`**
   - **asserts —** clean, unknown and near-miss queries mount the ordinary forest without witness
     controls/assets while preserving existing selection, camera, inspector, chat, scene and art
     policy.
3. **`ogaw-navigation-and-reduced-motion-use-the-product-state`**
   - **asserts —** repeated Next, Back and Replay traces drive equal public cue/progress/native-land/
     organic-frame/socket output; reduced motion immediately selects equivalent settled states and
     the same retained mature scene without remounting or a host timer.
4. **`ogaw-runtime-has-no-vendor-or-generated-land-dependency`**
   - **asserts —** Studio source, package dependencies and representative browser requests contain
     no PixelLab client/hostname/credential/model call and no generated island/coast/complete-scene
     asset; organic frames load only from the versioned local app-surface set.
5. **`ogaw-desktop-and-mobile-preserve-the-planted-scene`**
   - **asserts —** representative desktop and mobile sizes retain native coast, registered roots/
     sockets, mature footprint and controls inside one shared world framing with identical semantic
     output and no viewport-specific renderer.
6. **`ogaw-existing-studio-and-semantic-demo-contracts-stay-green`**
   - **asserts —** the full Studio command retains clean map, shared scene, selection/controller,
     Storybook/Vector, earlier semantic demo, legend, inspector, chat and camera regression walls.
